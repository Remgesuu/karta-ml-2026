# Карта ML 2026

Карта обучения машинному обучению на 45 недель в виде доски. Этапы роадмапа стоят рамками слева направо, линии внутри этапа отходят ветками, блоки тем показаны карточками со статусами. Пунктирные дуги показывают, какая тема нужна для какой.

Сайт: https://remgesuu.github.io/karta-ml-2026/

## Файлы

- `index.html` открывает доску в браузере. Её можно двигать, приближать и дорисовывать, но правки не сохраняются после перезагрузки.
- `karta-ml-2026.png` содержит всю карту одной картинкой.
- `karta-ml-2026.excalidraw` открывается на excalidraw.com и в Obsidian с плагином Excalidraw.
- `karta-ml-2026.canvas` открывается в Obsidian как доска Canvas.

## Откуда данные

Карта собрана из моего роадмапа, вопросов и задач Нарешки и моих учебных заметок. Внутри пунктов стоят темы курса Machine Learning with Python на Hyperskill. Статусы показывают мой прогресс на 6 ноября 2026 года.

## Сторонний код

Страница собрана из React, Excalidraw и других пакетов npm. Их лицензии лежат в `THIRD_PARTY_LICENSES.md`.
